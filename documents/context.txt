VISION
------
LaunchPad is a next-generation desktop rocket-design tool. The project is split into two major phases:
1. **The Manual Editor (Phase 1):** A complete, modernized replica of OpenRocket where users can 100% manually build, visualize, and simulate their own rockets part-by-part using a hierarchical component tree.
2. **The Optimizer (Phase 2):** A Genetic Algorithm (GA) extension where the user defines constraints (target altitude, stability) and the application automatically generates and evolves hundreds of rocket designs for them.

How the GA will work:
  - Each rocket's dimensions become a "genome" (body diameter, length, fin span,
    nose cone shape, etc.).
  - Hundreds of candidate rockets are evaluated across multiple generations.
  - Each generation keeps the best performers and breeds new designs.
  - Fitness is scored with Barrowman equations for stability and a physics model
    for apogee prediction.

What the finished product will look like:
  - A clean input dashboard where the user sets constraints.
  - A gallery of top-ranked rocket candidates after optimization.
  - Each card shows key stats (apogee, stability, diameter, motor).
  - The user picks a favorite and eventually exports it to a buildable format.

The long-term goal is a portfolio-level project bridging aerospace physics,
evolutionary computing, and interactive 3D graphics -- all running fully
offline on the user's device.

Fonts    : BrunoAce (titles), Rajdhani (UI/body text)

CURRENT STATE (as of 2026-05-19)
---------------------------------
Screens built:
  1. Project Screen (main scene)
	 - Top bar with a small 3D rocket logo (says "Launch Pad"), menu bar
	   (File, Edit, View, Help), and a home button that navigates back here.
	 - "Your Projects" header with a "+ New Project" button.
	 - A scrollable grid of project cards (4 columns).
	 - Empty state shown when no projects exist yet.

  2. Project Cards
	 - Dark styled PanelContainer cards (380x200 min).
	 - Show project name, description, motor class, target altitude, and
	   last-modified date.
	 - Delete button with confirmation dialog.
	 - Click a card to open its project (handler exists but is a TODO stub).

  3. 3D Rocket
	 - Built from three OBJ meshes (cylinder, fins, nose cone).
	 - Four Label3D pairs (text + shadow) wrapped around the body, driven by
	   an export variable "rocket_text".
	 - Rotates via _process (rotation disabled in the top-bar logo instance to
	   avoid an editor undo glitch).

Data layer:
  - ProjectManager autoload stores projects as .lpad JSON files in
	user://projects/.
  - ProjectData resource holds metadata (name, description, timestamps) and
	constraint fields (target_altitude, max_diameter, motor_class,
	stability_margin) plus GA result placeholders (generation_count,
	population_size, top_candidates).
  - Full CRUD: create, save, load, list (sorted by date), delete.

Previous intro screen was removed because it looked more like a game start
button than a professional engineering tool. The app now boots directly into
the Project Screen.

Known issues resolved:
  - Node-not-found errors on %NameLabel / %DateLabel / etc. were fixed by
	adding unique_name_in_owner to each label in project_card.tscn and using
	an await-ready guard in project_card.gd.
  - Editor undo glitch ("Condition !p_node->is_inside_tree() is true") was
	fixed by removing the @tool annotation from rocket.gd.

Top bar menus currently wired:
  File  -> New Project (works), Open Project Folder (works), Exit (works)
  Edit  -> Preferences (stub)
  View  -> Reset Layout (stub)
  Help  -> Documentation (stub), About LaunchPad (stub)
